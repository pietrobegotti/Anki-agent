# Istruzioni per l'LLM

- Scrivi una carta per ogni elemento richiesto dall'utente.
- Salva ogni carta come file JSON direttamente in `cards/`.
- Usa esclusivamente uno dei template JSON elencati sotto. Compila i campi del
  template senza aggiungerne, rimuoverne o rinominarne.
- Nomina ogni file `<id>_<word>.json`, usando la parola della carta al posto di
  `<word>`.
- Assegna a `<id>` un numero progressivo di sei cifre: inizia da `000001` e
  incrementalo per ogni nuova carta. Controlla i file già presenti in `cards/`;
  non riutilizzare ID e non sovrascrivere file.
- Scrivi nel file solo JSON valido, senza blocchi Markdown o testo aggiuntivo.
